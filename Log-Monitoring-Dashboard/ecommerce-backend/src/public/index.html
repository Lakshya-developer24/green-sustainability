API Tester Dashboard

Since the /login, /signup, and /order endpoints expect POST requests with data, you can use these buttons to easily trigger them right from your browser!

1. Signup (POST /signup)

Creates a new user in the PostgreSQL database.

2. Login (POST /login)

Authenticates the user and returns their User ID.

3. Get Products (GET /products)

Retrieves items. Includes a random delay to simulate slow requests (triggers WARN logs).

4. Submit Order (POST /order)

Creates an order. Has a 30% chance of payment failure (triggers ERROR logs).
